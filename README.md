# S9 Pro 电量托盘工具

适用于 Windows 10 x64 和前行者 **S9 Pro（非 V2）**。通过 USB HID 查询电量，无需保持官方网页或客户端运行，不需要管理员权限。

**1.2.3 无线事件更新修正版**：无线接收器上报有效电量变化后立即更新托盘，不再等下一次查询。每分钟查询继续校验状态，旧事件不会覆盖较新的查询；启动 100% 不提醒和充电提醒规则保持不变。

升级时先右键退出旧版，再运行新版；否则单实例保护会阻止启动新程序。本版本已通过软件测试，但充电事件是否发出、接收器能否在有线模式持续更新，仍需要实际 S9 Pro 验证。

## 使用

1. 将 `S9Battery-win-x64.zip` 解压到固定目录，双击 `S9Battery.exe`。程序自带 .NET 运行环境，无需安装依赖。
2. 托盘图标直接显示电量数字，例如 `85`。如果图标藏在右下角的 `^` 菜单中，将它拖到任务栏常驻区域。
3. 鼠标悬停可查看电量百分比、连接方式、充电状态和最近更新时间。
4. 充电时使用支持数据传输的 USB 线连接电脑。建议先保留 2.4G 接收器：程序保持有线充电状态，尝试从在线且型号验证通过的接收器补充电量。仅连接有线也会尝试监听电量事件，但不能保证鼠标会发送。仅支持一只 S9 Pro。
5. 右键提供立即刷新、提醒设置、预览通知、开机启动、导出诊断信息和退出。双击图标也可立即刷新。开机启动默认关闭；启用后请保留 exe 的位置，移动程序后重新启用。

托盘使用圆角深色徽标，透明边缘和细电量条。正常电量为浅白色，可信电量低于设置的阈值（默认 20%）时为暖橙色，与低电量通知配色一致。充电时有百分比则显示绿色数字，没有有效数字则显示绿色闪电，状态过期时为灰色。悬停可区分：

- `78%（接收器）`：本轮独立查询的接收器百分比。接收器必须在线、设备型号正确，且不能返回充电中的不可靠数值。
- `上报 78%（待核实）`：本次有线充电期间收到的主动事件数值。尚未经过实机验证，因此不用于估算时间或触发 100% 提示；超过 90 秒没有新事件会隐藏这个候选值。
- `充电时电量不可确认`：只有充电标志和不可信数值，或没有新的电量事件。不会用有线返回的 100 当作满电。

充电剩余时间使用至少三个不同的可信百分比读数，时间跨度至少三分钟、增长至少三个百分点才估算，显示“按近期速度约…分钟（后期可能变慢）”。读数来自待核实事件、增长不足、断开、超过三分钟的数据空档或电量下降时不显示估算。它是近期变化的线性估算，不是设备的充电完成时间。

100% 提醒仅在本次运行中观察到充电后，随后收到可信的 100% 时触发一次。启动时的首个读数只作为初始状态，已经 100% 不提醒；没有观察到充电，仅无线数字从 99 变成 100 也不提醒。重新插线时短暂断开或读取失败不会丢掉已经观察到的充电过程，因此之后收到有效 100% 仍可提醒；若停止充电后读到不足 100%，则结束这次充电提醒等待。刚提示后再次拔插不会重复提醒，新的充电提醒需要先有可信的不足 100% 读数。

若 100% 来自接收器且有线仍上报充电，通知会说明。**尚未确认独立的充电完成信号，因此电量达到 100% 仍不等于设备确认充电结束。** 实测用户曾在重新插线后看到鼠标指示灯变绿、软件更新出有效的 100%，但不能保证固件在不插拔时及时改变状态。

## 提醒设置与气泡

右键托盘图标 → **提醒设置…**，可以分别开关低电量和“充电后电量达到 100%”提醒。低电量阈值可以设为 1–100%，默认 20%。例如设为 30%，电量 30% 不提醒，可信新读数低于 30% 才提醒；启动或修改设置时已经低于阈值，也会提醒。

气泡是程序自己的窗口，显示在主屏幕右下角的任务栏上方，不使用 Windows 通知横幅，因此不依赖“专注助手 → 仅优先通知”的允许名单，也不要求托盘图标常驻。深色圆角卡片配电量圆环，低电量使用暖橙色，100% 使用绿色。弹出时不激活窗口，不抢占输入焦点；低电量显示约 12 秒，100% 显示约 8 秒，悬停暂停倒计时，左键点击任意位置关闭。同一时刻只显示一个气泡。锁屏、安全桌面或某些独占全屏应用仍可能遮挡该窗口。

**预览通知**提供两种气泡的演示，不需要电量真的达到阈值，也不影响真实提醒的去重。低电量仅使用在线且非充电的可信读数，设备断开、休眠、读取失败或候选事件不会触发。持续处于低电量时只提醒一次；正常开始充电后，或者电量恢复到阈值加 3 个百分点（最多 100%）后，再次低于阈值可重新提醒，避免读数在阈值附近波动时反复弹窗。修改阈值或重新启用提醒会重新判断，重启程序也会重新判断；提醒去重状态不跨程序重启保存。

设置保存到 `%LOCALAPPDATA%\S9Battery\settings.json`，下次启动自动恢复。提醒设置保存失败时保持原设置并显示错误。100% 提醒默认开启，仍沿用可信读数规则，不会因有线充电占位值 `E4` 弹出假满电提示。

使用电池时每 60 秒读取一次，充电时每 15 秒查询。无线在线且未上报充电时，新电量事件立即更新显示，悬停标注“上报收到于”；不因事件到达增加查询频率，仍保留每分钟查询校验。仅采用比当前电量读数更新、收到不超过 90 秒且数值在 0–100 的事件。已接受的无线事件读数保留到后续查询或新事件，不因事件过期或通道结束退回旧数字；设备离线、读取失败或切换连接后不会使用旧事件恢复在线状态。原始报数可能在相邻百分比间波动，程序按最新有效报数显示，不人为限制电量只能下降。

后台每 5 秒检查到期状态，HID 设备列表缓存 30 秒；设备插拔、恢复和手动刷新立即使缓存失效并查询，定期扫描兜底处理漏掉的插拔消息。无线鼠标休眠或关闭时保留最后的数字并显示“上次读数”；设备完全断开或查询失败时图标显示 `--`，悬停保留上次读数及时间。休眠设备每 15 秒重试，错误每 5 秒重试。这里的“休眠或关闭”表示接收器报告鼠标离线，协议不能区分这两个状态。

## 性能

程序继续使用 WinForms 和 Windows 原生绘图，不引入浏览器或新的 UI 框架。托盘图标仅在数字、颜色、状态或尺寸改变时重新生成；更新时间改变只更新悬停文字。设备枚举由每 5 秒改为缓存 30 秒，实际电量查询间隔不变，插拔事件和手动刷新仍立即查询。

通知使用每像素透明度，避免窗口区域整像素裁切导致的圆角锯齿。卡片内容在弹出或 DPI 改变时绘制一次，约 180 毫秒的淡入复用同一张图；随后停止重绘，仅每 250 毫秒检查悬停和自动关闭。通知关闭后停止计时器并释放原生绘图缓存。为减少持续绘图，取消原先不断重画的倒计时进度条，保留悬停暂停和点击关闭。没有通知时不运行动画计时器。

下载包仍包含 .NET 运行时以便直接使用，其文件体积不等于程序运行内存；开发环境尚不能实测 Windows 上的 CPU 和内存占用，不提供未经测量的性能数字。

## 首次实机验证

程序已经通过编译和自动化测试，保留原有真实查询报文回归，并对照官方 SDK 验证主动电量事件格式。但开发环境没有实际 S9 Pro，**新版事件监听和充电时接收器百分比仍需实测**。首次运行建议：

- 仅连接 2.4G 接收器，对照官方网页的电量。
- 保留接收器并插上充电数据线，观察悬停是否出现“接收器”百分比，充电数分钟后检查它是否上升。
- 拔掉接收器，仅用有线充电数分钟，观察是否出现“上报…（待核实）”。没有事件时应保持闪电图标，不显示假 100%。
- 如果仍看不到充电百分比，保持充电 5–10 分钟后导出诊断，查看通道是否打开、`BatteryEvents` 是否大于零；不必等充满才导出。
- 充电结束后切回无线，对照官方网页电量。若仍需研究充满状态，可在确认实际充满后导出诊断，以便比较设备原始状态；本版不提前推断完成。
- 拔插接收器、关闭再开启鼠标、电脑睡眠再恢复，确认自动恢复显示。
- 打开官方网页检查是否能同时使用。如果显示读取失败，关闭官方驱动后右键“立即刷新”；两者会向同一设备发送查询，是否互相干扰需要实测。
- 检查 Windows 100%、125%、150%、200% 显示缩放下的托盘数字。

## 没有电量或读数异常

先确认是 S9 Pro 而非 S9 Pro V2，连接电脑的线支持数据传输，鼠标已经开启。右键“立即刷新”，如果仍显示 `--`，使用“导出诊断信息…”保存 ZIP，用于进一步适配。

诊断 ZIP 包含本品牌的 HID 设备 VID/PID、Usage、Input/Feature 报文长度、物理设备容器标识、产品名称、事件通道状态，以及三个查询和电量事件的原始响应与错误；不记录按键、鼠标移动，也不自动上传。它可能包含设备标识信息。事件监听只打开型号已确认设备的厂商 collection，排除普通键盘/鼠标 collection。日志存放于 `%LOCALAPPDATA%\S9Battery`，轮换保留约 2 MB。退出程序后可删除该目录。

仅连接充电器、仅用供电线或蓝牙连接时，本工具无法通过 USB 获取新状态。Windows 不允许程序强制将托盘图标固定在常驻区域，需要用户手动调整。

## 从源码构建

安装 .NET 8 SDK，在项目根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

输出位于 `dist\win-x64\S9Battery.exe`，压缩包位于 `dist\S9Battery-win-x64.zip`。

单独运行无需外部测试框架的测试：

```powershell
dotnet run --project tests/S9Battery.Tests -c Release
```

核心协议、轮询和状态逻辑位于 `src/S9Battery.Core`；Windows HID 通信与托盘界面位于 `src/S9Battery.Tray`。详见 [协议说明](docs/PROTOCOL.md)。
